Production Line Transform Monitoring System
PLT Monitor
1. 프로젝트 개요
PLT Monitor는 Unity 기반 생산 라인 환경에서 이동 중인 다수 오브젝트의 Transform 데이터를 실시간으로 기록하고, 이를 산업용 대시보드 UI에서 그래프로 시각화하는 모니터링 시스템

핵심 목적: 오브젝트를 제어하는 것이 아니라, 생산 라인 상의 오브젝트 상태를 관찰·기록·분석

움직이는 오브젝트 → Transform 값 읽기 → 프레임 데이터 저장 → 그래프 UI 표시 → CSV / JSON 저장 및 불러오기

3. 구현사항
- 변화하는 오브젝트의 Position / Rotation / Scale, 각 XYZ 축 상태 그래프
- Position / Rotation / Scale XYZ 기록
- 16개 오브젝트 이상 추적
- 60FPS이상 유지
- 오브젝트당 600프레임 이상 기록 구조
- JSON 저장 / 불러오기
- CSV 저장 / 불러오기
- 파일 브라우저 UI 
- 그래프 UI 
- Live View 
- 상태 해석 패널 

4. 결과
생산 라인 씬에서 움직이는 16개 이상의 오브젝트 Transform 데이터를 실시간 수집하고, 산업용 UI에서 그래프로 시각화하며, CSV / JSON 저장·불러오기와 파일 브라우저 연동을 지원하는 Unity 모니터링 시스템

7. Transform Recorder 구조
7.1 오브젝트별 기록
각 추적 오브젝트는 scr_TransformRecorder를 통해 프레임 단위 데이터를 기록

7.2 기록 데이터
frameIndex
timeStamp
posX / posY / posZ
rotX / rotY / rotZ
scaleX / scaleY / scaleZ

- 오브젝트 상태 시각화용 원본 데이터 확보
- JSON / CSV 저장용 데이터 생성
- 그래프 분석용 데이터 유지

8. Recorder Manager 구조

scr_TransformRecorderManager

8.2 기능
16개 Recorder 관리
Start / Stop 구조
프레임 데이터 수집
저장 시 Recorder 전체 데이터를 세션 단위로 집계

9. Save / Load 구조
9.1 관련 스크립트
scr_TransformDataSaveLoadManager
NST_Json
NST_CSV
TransformMonitoringSaveData
TransformObjectRecordData
TransformFrameData

9.2 SaveLoadManager 기능
scr_TransformDataSaveLoadManager는 저장 폴더 경로 생성, 기본 JSON 경로 반환, 신규 CSV 경로 생성, Recorder 데이터를 세션 구조로 집계, JSON/CSV 저장, 경로 기반 JSON/CSV 로드지원

9.3 저장 구조
JSON: transform_record.json (txt 파일)
CSV: transform_record_0000000_000000.csv (Exel 파일)
Sheet 생성: 
ObjectName / FrameIndex / TimeStamp / PosX PosY PosZ / RotX RotY RotZ / ScaleX ScaleY ScaleZ

JSON 저장 UI 상태 메시지 
CSV 저장 UI 상태 메시지 
Show JSON / Show CSV 모드 표시 
파일 선택 후 Selected 표시 
Load Selected 동작 

10. Graph System 구조
10.1 구성
GraphSystem
├ GraphDataProvider
├ GraphRenderer
├ GraphUIController
├ GraphLiveViewController
├ TransformGraphOverviewController
├ TransformOverviewGraphCard
└ FileBrowserUI

10.2 역할
GraphDataProvider: Recorder 데이터를 그래프용 포인트로 변환
GraphRenderer: 단일 그래프 / 다중 그래프 렌더링
GraphUIController: 모드, 카테고리, 축, 오브젝트 선택 및 UI 동기화
GraphLiveViewController: Live View 카메라 및 확대 패널 제어
OverviewController / OverviewGraphCard: 전체 박스 소형 그래프 카드 표시
FileBrowserUI: 저장 파일 목록 및 버튼 UI 제어
