# 06. Known Issues

## Save JSON·CSV 순간 CPU·GC Spike

### 현상

Save JSON 또는 Save CSV를 실행할 때 CPU와 GC 사용량이 순간적으로 증가하고 FPS가 일시 하락합니다. 기존 QA 기록에서는 약 40FPS 전후까지 내려간 뒤 일반 실행 수준으로 회복했습니다.

### 원인 범위

현재 다음 작업이 Unity 메인 스레드에서 연속 수행됩니다.

1. 최대 16 × 600프레임 복사
2. 세션 DTO와 대상별 프레임 목록 생성
3. JSON 문자열 또는 CSV Dictionary 행 생성
4. 파일 쓰기

### 영향

- 저장 버튼을 누른 순간에 한정된 일시적 부하
- 저장 이후 일반 모니터링 FPS 회복
- 기존 검증 범위에서는 메모리 폭주나 기능 중단 없음

### 개선 방향

- Recorder 데이터의 순수 스냅샷 구성
- 프레임 복사와 직렬화 작업 분할
- 백그라운드 직렬화가 가능한 데이터 구조 검토
- CSV 행을 한 번에 메모리에 구성하지 않는 스트리밍 출력
- 저장 진행·완료·실패 상태 표시

## Load Selected 구현 범위

선택한 JSON은 `TransformMonitoringSaveData`로 역직렬화하고, CSV는 행 Dictionary 목록으로 파싱합니다. 성공 여부는 상태 메시지로 표시합니다.

현재 파싱된 데이터는 Recorder·Data Provider·Graph UI에 다시 전달하지 않습니다.

**개선 방향**

- 로드 세션 전용 데이터 소스
- 현재 세션과 과거 세션 모드 분리
- 과거 그래프 재생과 두 세션 비교
- 파일 메타데이터와 세션 요약 표시

## 규칙 기반 Meaning Analyzer

Meaning Analyzer는 Position Z를 전방 이송축으로 가정하고, 최근 30개 포인트의 Delta와 Range를 고정 임계값으로 해석합니다.

따라서 다른 좌표계, 설비 속도나 대상 크기에 그대로 적용할 수 있는 범용 이상 탐지 모델이 아닙니다.

**개선 방향**

- 설비별 좌표·임계값 설정 파일
- 기준 구간 자동 보정
- 실제 센서 데이터 기반 임계값 검증
- 통계 또는 학습 모델과 규칙 결과 비교

## 성능 검증 범위

성능 검증은 개인 PC, Windows, Box 16개와 대상별 600프레임 기준입니다. 장시간 무중단 실행, 다양한 하드웨어와 더 큰 데이터 규모는 검증하지 않았습니다.

**개선 방향**

- 고정 시나리오 기반 반복 Profiling
- 대상 수·프레임 수 단계별 부하 테스트
- GC Alloc, Main Thread와 파일 크기 수치 기록
- 원본 Profiler Capture 보관
